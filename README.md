# Cookies Tracker 🍪

بوت ديسكورد لإدارة أعمال فريق كوكيز: تسجيل الفصول المنجزة بتخصصاتها، حساب المستحقات،
المكافآت والخصومات، تقارير الدفع الشهرية، والإحصائيات الحية.

مبني بالكامل على نظام **Components V2** بلغة التصميم البصرية المنقولة من بوت السحب ZEUS —
بطاقات حاوية موحدة بألوان الحالة، رؤوس بصورة مصغرة (**صورة البوت للبطاقات العامة،
وصورة العضو المعنيّ في كل بطاقاته**)، فواصل، شريط تقدم `▰▱`، قوائم مراحل `✓ ▸ · ✗ ⊘`،
وتذييل `-# Cookies Tracker`.

## 🎨 لغة التصميم (منقولة من بوت السحب ZEUS)

| العنصر | القيمة |
|---|---|
| الألوان | ذهبي `0xd4af37` (عام/معلومة) • أخضر `0x57f287` (نجاح) • أحمر `0xed4245` (فشل/رفض) • رمادي `0x95a5a6` (إلغاء) |
| البنية | حاوية واحدة (Container type 17) لكل رسالة + رأس Section بصورة مصغرة + فواصل (type 14) |
| الأزرار | رابط style 5 • تأكيد/حذف style 4 (Danger) • ثانوي style 2 • حفظ/نشط style 3 (Success) |
| التنقل | `◀ السابق` / `صفحة X من Y` (معطّل) / `التالي ▶` + `عودة إلى … ↩` |
| التقدم | `▰▰▰▱▱▱▱▱▱▱ **3 / 5**` (10 خانات دائمًا) |
| المراحل | `✓` مكتملة • `▸` حالية • `·` انتظار • `✗` فاشلة • `⊘` معطلة/مستثناة |
| التذييل | `-# Cookies Tracker` في نهاية كل بطاقة |

كل مكونات التصميم معرفة في `ui/cards.py` وهي المصدر الوحيد للهوية البصرية.

## 🤖 الهوية

- الاسم الظاهر يُفرض تلقائيًا: **Cookies Tracker** (المعرف: `Cookies_Tracker`)
- حالة النشاط: `WATCHING — Cookies Tracker | /مساعدة`

## 📋 الأوامر (45 أمر slash + أوامر نصية)

### الأعضاء
| الأمر | الوظيفة |
|---|---|
| `/تسجيل` | تسجيل فصول منجزة مع فلترة المدفوع تلقائيًا وإيصال فوري بصورة العضو وقائمة مراحل ✓ |
| `/أعمالي` | لوحتك الشخصية مجمعة (أعمال/مكافآت/خصومات/صافي) بقائمة اختيار تفاعلية |
| `/شغل` | ملخص شغل أي عضو — بصورة العضو وتفاصيل دقيقة لكل عمل (ملخص ← تخصصات ← فصول مرتبة رقميًا) |
| `/ملخص_شهري` | ملخص الشهر الحالي: الصافي + تفصيل الأعمال والتخصصات |
| `/تقريري` | تقرير آخر 7 أيام |
| `/تعديل` | تعديل آخر سجل أضفته |
| `/اسعار` | أسعار التخصصات بأشرطة ▰▱ + التخصيصات الخاصة بالأعمال |
| `/الأعمال` | قائمة الأعمال مرتبة حسب النشاط (عمل ← عضو ← فصول مرتبة رقميًا) |
| `/احصائيات` | لوحة تفاعلية: نظرة عامة/تخصصات بأشرطة ▰▱/زمني/الأفضل |
| `/توب` | ترتيب الأعضاء بالمعايير الثلاثة مع الميداليات 🥇🥈🥉 |
| `/مساعدة` (`/اوامر`) | دليل الأوامر الكامل |

### لوحة التحكم — أزرار تُنفّذ لا توجّه
كل زر داخل `/لوحة_التحكم` ينفّذ قسمه مباشرة في مكان اللوحة (مع زر عودة):
`👥 الأعضاء` • `🏆 التوب` • `📊 الإحصائيات` • `💳 تقرير الدفع` • `🛠️ أعضاء تخصص` • `📆 ملخص شهري`

### /الأعضاء — التصميم المريح
سطر واحد لكل عضو (ميدالية + منشن + فصول + أعمال + صافي)، 8 أعضاء بالصفحة،
وقائمة منسدلة **«اختر عضواً لعرض تفاصيله الدقيقة»** تفتح بطاقة كاملة:
الإجماليات، تفصيل الأعمال بأشرطة ▰▱، تفصيل التخصصات، وآخر 5 سجلات — بصورة العضو.

أوامر نصية: `!تحليل` (نفس التسجيل مع بطاقة طلب مدخلات) • `!حذف` • `!حذف_الكل` • `!أعمالي` • `!شغل` • `!تحديد_قنوات`
